公文准式安装完成

请先保存文档，完全退出办公软件，再打开新的文档。

WPS 用户
    使用 JS 加载项，不需要启用 VBA 或导入 ZIP。
    功能区应出现“公文准式”；当前版本提供页面、标题、正文、文字清理、页码和页眉处理。
    安装按当前用户生效，其他 Windows 用户需要分别安装。
    如果仍未出现，请确认 WPS 安装版本具备文字 JS 加载项能力。
    JS 版尚未包含 VSTO 全部功能及 42 个 VBA 脚本。

Microsoft Word 用户
    使用 VSTO 加载项，需要 .NET Framework 4.8 和 VSTO 运行库。
    如未出现选项卡，在“文件 → 选项 → 加载项 → COM 加载项”中查看公文准式。

卸载
    Windows“已安装的应用”中分别卸载“公文准式（WPS）”或“公文准式（Word）”。
    JS 卸载只移除本插件注册，保留其他 JS 加载项，并恢复安装前本插件的 WPS VSTO 白名单状态。
    Linux：在解压目录执行 sh install.sh --uninstall。
