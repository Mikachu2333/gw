# DataBuffer.Id

缓冲区的唯一标识 ID。

## 语法

express.**Id**

express   一个代表 **DataBuffer** 对象的变量。

## 类型

number，只读。

## 说明

由 [CreateDataBuffer](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/Application/member/CreateDataBuffer) 创建时自动分配的递增整数 ID，可用于 [GetDataBuffer](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/Application/member/GetDataBuffer) 和 [DeleteDataBuffer](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/Application/member/DeleteDataBuffer)。
