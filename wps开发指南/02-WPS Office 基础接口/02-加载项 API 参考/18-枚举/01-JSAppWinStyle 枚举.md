# JSAppWinStyle 枚举

[Shell](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/Shell) 的窗口样式，控制新启动进程的窗口显示方式。

## 说明

窗口样式仅在 Windows 上生效，macOS 和 Linux 上会被忽略。

## 成员

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| jsHide | 0 | 隐藏窗口。 |
| jsNormalFocus | 1 | 正常大小显示并获得焦点。 |
| jsMinimizedFocus | 2 | 最小化显示并获得焦点。 |
| jsMaximizedFocus | 3 | 最大化显示并获得焦点。 |
| jsNormalNoFocus | 4 | 正常大小显示但不获得焦点。 |
| jsMinimizedNoFocus | 6 | 最小化显示且不获得焦点。 |
