# FileSystem.copyFileSync

生成文件副本

## 语法

express.copyFileSync(SrcFilePath, DestFilePath)

express   一个代表 FileSystem 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| SrcFilePath | 必选 | String | 源文件的路径包括文件名称 |
| DestFilePath | 必选 | String | 新创建的文件副本文件名称 |
