# RibbonUI.ActivateTabQ

激活自定义功能区，参数为自定义功能区名称及命名控件。

## 语法

express.**ActivateTabQ(ControlID, Namespace)**

express   一个代表 **RibbonUI** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| ControlID | 必选 | string | 自定义功能区控件 Id。 |
| Namespace | 必选 | string | 自定义功能区命名空间。 |

## 返回值

void
