# RibbonUI.ActivateTabMso

激活内置的功能区，参数为指定的功能区名称。

## 语法

express.**ActivateTabMso(ControlID)**

express   一个代表 **RibbonUI** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| ControlID | 必选 | string | 内置功能区选项卡的 Id。 |

## 返回值

void
