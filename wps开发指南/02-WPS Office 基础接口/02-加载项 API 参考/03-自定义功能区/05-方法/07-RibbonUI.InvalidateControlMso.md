# RibbonUI.InvalidateControlMso

指定更新一个内置控件，参数为内置控件 Id。

## 语法

express.**InvalidateControlMso(ControlID)**

express   一个代表 **RibbonUI** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| ControlID | 必选 | string | 要刷新的内置功能区控件 Id。 |

## 返回值

void
