# WebDialog.ID

对话框的唯一标识 ID。

## 语法

express.**ID**

express   一个代表 **WebDialog** 对象的变量。

## 类型

number，只读。

## 说明

由 [CreateWebDialog](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/Application/member/CreateWebDialog) 创建时自动分配的递增整数 ID，可传给 [GetWebDialog](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/Application/member/GetWebDialog) 获取引用。
