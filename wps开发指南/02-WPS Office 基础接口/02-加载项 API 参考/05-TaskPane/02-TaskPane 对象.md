# TaskPane 对象

 **TaskPane** 对象是一个用来浏览网页的用户界面面板

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Delete](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/Delete) | 此方法用于删除当前的**Taskpane**。 |
| [Navigate](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/Navigate) | 此方法用于在当前的**Taskpane**上重新载入url对应的网页。 |

## 属性

| **名称** | **说明** |
| :------ | :------- |
| [DockPosition](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/DockPosition) | 可读写，设置或返回一个整型，代表**Taskpane**的停靠位置。 |
| [Height](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/Height) | 返回一个整数，此整数代码**Taskpane**的高度。 |
| [ID](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/ID) | 返回一个整数，此整数代码**Taskpane**的ID。 |
| [Visible](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/Visible) | 可读写，设置或返回一个bool类型，代表**Taskpane**的可见性。 |
| [Width](/app-integration-dev/wps365/client/wpsoffice/jsapi/addin-api/TaskPane/member/Width) | 返回一个整数，此整数代码**Taskpane**的宽度。 |
