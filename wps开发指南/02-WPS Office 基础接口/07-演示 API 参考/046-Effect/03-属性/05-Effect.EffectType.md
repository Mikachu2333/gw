# Effect.EffectType

设置或返回 **MsoAnimEffect** 常量，该常量代表动画效果的类型。可读/写。



## 语法

express.**EffectType**

express   一个代表 **Effect** 对象的变量。

## 类型

MsoAnimEffect

## 示例


```JavaScript
/*本示例将动画效果更改为随机线条动画。*/
function test() {
    let effect = ActivePresentation.Slides.Item(1).TimeLine.MainSequence.Item(1)
    effect.EffectType = msoAnimEffectRandomBars
}
```


```JavaScript
/*本示例显示活动窗口选定的第一张幻灯片的主动画序列时间线的第二个动画效果的类型是否为msoAnimEffectAppear。*/
function test() {
    let effect = ActiveWindow.Selection.SlideRange.Item(1).TimeLine.MainSequence.Item(2)
    alert(effect.EffectType == msoAnimEffectAppear)
}
```
