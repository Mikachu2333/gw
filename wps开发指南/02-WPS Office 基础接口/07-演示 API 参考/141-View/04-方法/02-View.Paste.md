# View.Paste

将剪贴板上的内容粘贴到活动视图中。试图将对象粘贴到不接受它的视图中会导致错误。



## 语法

express.**Paste()**

express   一个代表 **View** 对象的变量。

## 返回值

void

## 说明


试图将对象粘贴到不接受它的视图中会导致错误。

将剪贴板内容粘贴到窗口中之前，请使用 **[ViewType](/app-integration-dev/wps365/client/wpsoffice/jsapi/wpp/DocumentWindow/member/ViewType)** 属性设置窗口视图。下表显示了可以粘贴到每个视图中的内容。

| 视图  | 可以从剪贴板中粘贴以下内容  |
| ----------- | -------- |
| 幻灯片视图或备注页视图 | 形状、文本或整张幻灯片。如果从剪贴板粘贴一个幻灯片，该幻灯片的图像将作为嵌入对象被插入到幻灯片、母版或备注页中；如果选中形状，粘贴的文本将附加到形状文本之后；如果选中文本，粘贴的文本将替换选中的文本；如果选中任何其他对象，粘贴的文本将被放到它自己的文本框中。粘贴的形状将被放到 z 顺序的最上端且不会替换选中的形状。 |
| 大纲视图        | 文本或整张幻灯片。不能向大纲视图粘贴形状。粘贴的幻灯片将被插到光标所在的幻灯片之前。                                                                                                                     |
| 幻灯片浏览视图     | 整张幻灯片。不能向幻灯片浏览视图粘贴形状或文本。粘贴的幻灯片将被插到光标处或演示文稿中最后选中的一张幻灯片之后。                                                                                                       |

如果未完全下载源内容，此方法将失败并发生错误。



## 示例


```JavaScript
/*本示例在第一个窗口中复制选定幻灯片到剪贴板并将其粘贴到第二个窗口的视图中。如果剪贴板的内容不能粘贴到第二个窗口的视图中（例如：如果试图粘贴一形状到幻灯片浏览视图中）本示例失败。*/
function test() {
    Windows.Item(1).Selection.Copy()
    Windows.Item(2).View.Paste()
}
```


```JavaScript
/*本示例将第一个窗口中选定内容复制到剪贴板（请确认第一个窗口在幻灯片视图中），然后将剪贴板内容粘贴到第二个窗口的视图中。*/
function test() {
    Windows.Item(1).Selection.Copy()
    Windows.Item(2).ViewType = ppViewSlide
    Windows.Item(2).View.Paste()
}
```
