# Shapes.AddChart

向演示文稿中添加图表。



## 语法

express.**AddChart(Type, Left, Top, Width, Height)**

express   一个代表 **Shapes** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Type | 可选 | XlChartType | 图表的类型。 |
| Left | 可选 | number（float 精度） | 左侧尺寸。 |
| Top | 可选 | number（float 精度） | 顶端尺寸。 |
| Width | 可选 | number（float 精度） | 图表的宽度。 |
| Height | 可选 | number（float 精度） | 图表的高度。 |

## 返回值

Shape
