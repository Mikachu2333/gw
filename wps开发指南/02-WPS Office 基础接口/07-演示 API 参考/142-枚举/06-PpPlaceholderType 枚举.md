# PpPlaceholderType 枚举

指定占位符的类型。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **ppPlaceholderMixed** | -2 | 混合 |
| **ppPlaceholderTitle** | 1 | 标题 |
| **ppPlaceholderBody** | 2 | 正文 |
| **ppPlaceholderCenterTitle** | 3 | 居中标题 |
| **ppPlaceholderSubtitle** | 4 | 副标题 |
| **ppPlaceholderVerticalTitle** | 5 | 垂直标题 |
| **ppPlaceholderVerticalBody** | 6 | 垂直正文 |
| **ppPlaceholderObject** | 7 | Object |
| **ppPlaceholderChart** | 8 | 图表 |
| **ppPlaceholderBitmap** | 9 | 位图 |
| **ppPlaceholderMediaClip** | 10 | 媒体剪辑 |
| **ppPlaceholderOrgChart** | 11 | 组织图 |
| **ppPlaceholderTable** | 12 | 表格 |
| **ppPlaceholderSlideNumber** | 13 | 幻灯片编号 |
| **ppPlaceholderHeader** | 14 | 标头 |
| **ppPlaceholderFooter** | 15 | 页脚 |
| **ppPlaceholderDate** | 16 | 日期 |
| **ppPlaceholderVerticalObject** | 17 | 垂直对象 |
| **ppPlaceholderPicture** | 18 | 图片 |
| **ppPlaceholderCameo** | 19 | 客串 |
