# PpPrintRangeType 枚举

指定演示文稿打印区域的类型。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **ppPrintAll** | 1 | 打印演示文稿中的所有幻灯片。 |
| **ppPrintCurrent** | 3 | 打印演示文稿中的当前幻灯片。 |
| **ppPrintNamedSlideShow** | 5 | 打印命名的幻灯片。 |
| **ppPrintSelection** | 2 | 打印所选幻灯片。 |
| **ppPrintSlideRange** | 4 | 打印若干张幻灯片。 |
