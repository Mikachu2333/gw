# PpBaselineAlignment 枚举

指定段落的基准线对齐方式。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **ppBaselineAlignBaseline** | 1 | 向基准线对齐。 |
| **ppBaselineAlignCenter** | 3 | 居中对齐。 |
| **ppBaselineAlignFarEast50** | 4 | FarEast50 对齐。 |
| **ppBaselineAlignMixed** | -2 | 混合对齐方式。 |
| **ppBaselineAlignTop** | 2 | 顶端对齐。 |
