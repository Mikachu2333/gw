# DataSource.SetDemoRangeItem

填充示例数据。

## 语法

express.SetDemoRangeItem(rowsIdx, colsIdx, value)

express   一个代表 DataSource 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| rowsIdx | 必选 | Number | 行数索引 |
| colsIdx | 必选 | Number | 列数索引 |
| value | 必选 | Variant | 要填充的值 |
