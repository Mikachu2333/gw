# DataSource.RegisterDataRange

向当前DataSource对象注册DataRange对象。

## 语法

express.RegisterDataRange(Key, Value)

express   一个代表 DataSource 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Key | 必选 | String | DataRange对象的键 |
| Value | 必选 | Object | DataRange对象 |

## 返回值

Boolean
