# 概述

这是一套通用的加载项函数注册及调用机制，能够安全且高效地从js宏或加载项调用加载项中注册的函数。

# 特性
- 支持从js宏调用加载项函数
- 支持从加载项调用同一加载项其他浏览器注册的函数
- 支持传递基础数据类型和wps api对象

# API

```js
interface Application {
    WPSAddIns: WPSAddIns
    CurrentWPSAddIn: WPSAddIn;// js宏下调用时抛异常
}
interface WPSAddIns {
    readonly Count: number;
    Item(item: number|string): WPSAddIn|null; // index是从1开始的
}
interface WPSAddIn {
    readonly Name: string;
    Functions(): WPSAddInFunctions;
}
interface WPSAddInFunctions {
    Item(item: string|number): WPSAddInFunction|null; // index是从1开始的  
    //仅限于当前加载项
    Register(name: string, func: Function, isAsync: boolean = false): WPSAddInFunction;        
    //仅限于当前加载项
    UnRegister(name: string): boolean;
    readonly Count: number;
}
interface WPSAddInFunction {
    readonly Name: string;
    Call(...args: any[]): any;
    readonly IsAsync: boolean; // 预留字段
    
    // 仅函数注册者允许设置
    AllowJsIdeCall: boolean; // = false. 是否允许js宏调用此函数
}
```

# 类型系统

## 支持的类型

- number (不支持`nan`和`Infinity`和`-Infinity`)
- bigint(要在C++的 `int64_t`或`uint64_t`的取值范围内，否则会转为浮点数或字符串)
- string
- boolean
- Date (只能精确到秒。如果精度要求较高，建议用bigint或string传递时间)
- `T[]` (元素不能是对象，嵌套数组会被js宏处理成张量类型。支持一维数组或矩阵)
- wps api 对象 (比如Range，Workbook，Worksheet等)
- null (会被处理成undefined)
- undefined

### js宏支持的类型
可以在js宏中作为参数传递给加载项函数的类型
- `Map<string,V>`(会被转为js对象，`Record<string,V>`类型)
### 加载项支持的类型
可以在加载项中作为参数或返回值的类型
- object (不能是空对象，相当于typescript的`Record<string,V>`类型)

# 权限

- 注册函数

只有加载项可以注册函数。一个加载项只能注册当前加载项的函数

- 删除函数

只有加载项可以删除函数。一个加载项只能删除当前加载项的函数

- 设置函数属性

只有函数所属的加载项可以设置函数的AllowJsIdeCall属性，这个属性决定是否允许js宏调用

- 调用函数

一个加载项可以调用当前加载项注册的函数，无法调用其他加载项注册的函数

js宏可以调用加载项注册的任意函数，前提是函数的AllowJsIdeCall属性为true

# 生命周期

## 注册函数

```js
let func = Application.CurrentWPSAddIn.Functions.Register("functionName", (arg0, arg1)=>{
    return arg0 + arg1
})
func.AllowJsIdeCall = true;
```

### 提示

- 如果重复注册函数，会覆盖已经注册的函数
- 如果使用vue或react或者其他单页面的前端框架，请注意只在一个浏览器中注册函数，防止对话框或者任务窗格浏览器覆盖掉加载项根浏览器注册的函数

比如vue中，可以在Root.vue或者Dialog.vue等文件中注册函数

- 建议在函数中添加try catch。jside中无法获取加载项中抛出的异常

例如一个简单的函数封装器，用于简化注册函数的步骤，同时添加错误处理

```js
function register(name, func) {
    let f = Application.CurrentWPSAddIn.Functions.Register(name, function() {
        try {
            return func.apply(this, arguments);
        } catch (e) {
            console.error(`Error in function ${name}:`, e);
            return null;
        }
    });
    f.AllowJsIdeCall = true;
    return f;
}
```

## 调用函数

```js
const addin = Application.WPSAddIns.Item("addinName")
const func = addin.Functions.Item("functionName")
func.Call(arg0, arg1)
```

### 提示

- 如果多次查询加载项，建议Application.WPSAddIns对象保留下来，而不是每次使用都获取。获取Application.WPSAddIns会扫描加载项，性能消耗较大
- 建议将加载项对象保存下来，重复使用
- 建议将函数对象保存下来，重复使用

如果调用函数时抛异常，那么可能是以下情况

1. 函数已经被删除
2. 参数类型无法传递给浏览器
3. 浏览器被关闭

## 删除函数

```js
Application.CurrentWPSAddIn.Functions.Unregister("functionName");
```

## 浏览器关闭

浏览器关闭时会删除其注册的函数。如果函数对象仍然存在，那么函数对象被调用时直接抛异常
