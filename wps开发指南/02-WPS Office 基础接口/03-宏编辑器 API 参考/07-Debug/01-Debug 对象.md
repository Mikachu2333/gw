# Debug 对象

调试输出对象，用于在宏编辑器的"立即窗口"中显示信息。

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Print](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/Debug/member/Print) | 在宏编辑器的"立即窗口"中输出文本。 |
| [ShowWeak](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/Debug/member/ShowWeak) | 遍历当前 JS 引擎中所有 Persistent 句柄并按类型分组统计输出。 |
| [GC](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/Debug/member/GC) | 手动触发 V8 引擎的垃圾回收。 |
