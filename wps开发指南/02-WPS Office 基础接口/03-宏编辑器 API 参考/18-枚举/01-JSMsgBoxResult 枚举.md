# JSMsgBoxResult 枚举  

---

用户点击MsgBox弹出消息框的按钮。 

| 名称                 | 值 | 说明     |
| ------------------ | - | ------ |
| **jsResultOK**     | 1 | **确定** |
| **jsResultCancel** | 2 | **取消** |
| **jsResultAbort**  | 3 | **中止** |
| **jsResultRetry**  | 4 | **重试** |
| **jsResultIgnore** | 5 | **忽略** |
| **jsResultYes**    | 6 | **是**  |
| **jsResultNo**     | 7 | **否**  |
