# FV

计算在固定利率下定期等额付款的投资的终值。

## 语法

```typescript
function FV(Rate: number, NPer: number, Pmt: number, PV?: number, Due?: number): number
```

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Rate | 必选 | number | 每期利率。例如年利率 6% 按月付款时传入 `0.06 / 12`。 |
| NPer | 必选 | number | 总付款期数。 |
| Pmt | 必选 | number | 每期付款金额（支出为负）。 |
| PV | 可选 | number | 现值（初始投入，支出为负）。省略时默认为 `0`。 |
| Due | 可选 | number | 付款时机：`0` 期末付款（默认），非零值期初付款。 |

## 返回值

投资终值。

## 说明

基于固定利率和等额付款，计算投资或贷款在所有期数结束后的价值。
遵循现金流符号约定：支出（如定期存款）为负数，收入（如到期收回）为正数。
Due 参数控制付款时机：0 表示期末付款（默认），非零值表示期初付款。

## 示例

```javascript
/* 计算定期存款终值 */
function test() {
  const fv = FV(0.06 / 12, 120, -500)
  Debug.Print("10年每月存500元的终值：" + fv)
}
```

```javascript
/* 有初始投入的终值 */
function test() {
  const fv = FV(0.05 / 12, 60, -200, -10000)
  Debug.Print("5年终值：" + fv)
}
```
