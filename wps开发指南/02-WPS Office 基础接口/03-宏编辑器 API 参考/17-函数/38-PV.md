# PV

计算在固定利率和等额付款条件下一系列未来付款的现值。

## 语法

```typescript
function PV(Rate: number, NPer: number, Pmt: number, FV?: number, Due?: number): number
```

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Rate | 必选 | number | 每期利率（小数形式）。不能等于 `-1`。 |
| NPer | 必选 | number | 总付款期数。 |
| Pmt | 必选 | number | 每期付款金额（支出为负）。 |
| FV | 可选 | number | 终值。省略时默认为 `0`。 |
| Due | 可选 | number | 付款时机：`0` 期末付款（默认），非零值期初付款。 |

## 返回值

现值。

## 说明

现值是一系列未来等额付款在当前时点的总价值。用于评估一笔贷款能借多少、一份年金值多少。
遵循现金流符号约定：支出为负数，收入为正数。
Rate 不能等于 `-1`。PV 是 [FV](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/FV) 的逆运算。

PV、[FV](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/FV)、[Pmt](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/Pmt)、[NPer](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/NPer)、[Rate](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/function/Rate) 是同一组金融变量的五个方面——已知其中四个即可求第五个。

## 示例

```javascript
/* 计算贷款在当前利率下能借到的最大金额 */
function test() {
  const maxLoan = PV(0.06 / 12, 360, -2000)
  Debug.Print("最多可借：" + maxLoan.toFixed(2) + " 元")
}
```

```javascript
/* 评估年金的现值 */
function test() {
  const annuityValue = PV(0.08 / 12, 240, -3000, 0, 1)
  Debug.Print("年金现值（期初付款）：" + annuityValue.toFixed(2))
}
```
