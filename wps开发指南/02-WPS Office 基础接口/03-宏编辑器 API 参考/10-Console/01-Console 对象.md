# Console 对象

控制台输出对象，提供浏览器风格的日志输出和清除功能。

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [log](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/Console/member/log) | 在宏编辑器的"立即窗口"中输出一条日志。 |
| [clear](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/Console/member/clear) | 清空宏编辑器"立即窗口"中的所有内容。 |
