# FFIFunction 对象

原生函数包装对象，通过 [FFILibrary.LoadFunction](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/FFILibrary/member/LoadFunction) 或 [FFI.CreateFunction](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/FFI/member/CreateFunction) 获取。

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Call](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/FFIFunction/member/Call) | 调用包装的原生函数。 |
| [ToPointer](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/FFIFunction/member/ToPointer) | 获取原生函数的地址，返回 [FFIPointer](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-api/FFIPointer/obj)。 |
