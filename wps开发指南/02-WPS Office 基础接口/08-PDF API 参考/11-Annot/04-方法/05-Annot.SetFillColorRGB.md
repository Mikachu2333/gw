# Annot.SetFillColorRGB

设置注释的填充颜色。

## 语法

express.**SetFillColorRGB**

express   一个代表 **Annot** 对象的变量。

## 参数说明

| 参数 | 类型 | 说明 |
|-----|------|------|
| Red | long | 红色分量 (0-255) |
| Green | long | 绿色分量 (0-255) |
| Blue | long | 蓝色分量 (0-255) |

## 返回值

无

## 示例

```JavaScript
annot.SetFillColorRGB(255, 255, 0); // 黄色填充
```
