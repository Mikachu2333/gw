# Annot.SetColorRGB

设置注释的边框/线条颜色。

## 语法

express.**SetColorRGB**

express   一个代表 **Annot** 对象的变量。

## 参数说明

| 参数 | 类型 | 说明 |
|-----|------|------|
| Red | long | 红色分量 (0-255) |
| Green | long | 绿色分量 (0-255) |
| Blue | long | 蓝色分量 (0-255) |

## 返回值

无

## 示例

```JavaScript
annot.SetColorRGB(255, 0, 0); // 红色
```
