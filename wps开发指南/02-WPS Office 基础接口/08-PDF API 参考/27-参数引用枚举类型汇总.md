## 保存选项 （PdfSaveOptions）

**引用位置**：

| 对象 | 成员 | 说明 |
|------|------|------|
| Window | Close | 参数 |
| Events | ApplicationQuit | 参数 |

### 枚举值

| **值** | **名称** | **说明** |
| :------ | :------ | :------ |
| 0 | pdfDoNotSaveChanges | 不保存更改 |
| -1 | pdfSaveChanges | 保存更改 |
| -2 | pdfPromptToSaveChanges | 提示保存 |

## 线型样式 (Annot.LineStyle)

适用于形状类注释（Line、Square、Circle、Arrow、Polygon、PolyLine 等）的边框线型，通过 dashPattern 控制。

**引用位置**：

| 对象 | 成员 | 说明 |
|------|------|------|
| Annot | LineStyle | 属性 |

### 枚举值

| **值** | **说明** |
| :------ | :------ |
| 0 | 实线（Solid） |
| 1 | 点线（Dashed，dash pattern [2, x]） |
| 2 | 短虚线（Dashed，dash pattern [3, x]） |
| 3 | 中虚线（Dashed，dash pattern [4, x]） |
| 4 | 点划线（Dashed，dash pattern [4, 3, 2, 3]） |
| 5 | 长点划线（Dashed，dash pattern [4, 3, 16, 3]） |
| 6 | 双点划线（Dashed，dash pattern [8, 4, 4, 4]） |
| 7 | 云朵线（小波瓣，Cloudy，intensity = 1） |
| 8 | 云朵线（大波瓣，Cloudy，intensity = 2） |

## 页面插入位置 (insertPositionType)

**引用位置**：

| 对象 | 成员 | 说明 |
|------|------|------|
| Pages | InsertBlankPage | 参数 insertPositionType |
| Pages | InsertPagesFromFile | 参数 insertPositionType |

### 枚举值

| **值** | **说明** |
| :------ | :------ |
| 0 | 插入到文档最前（第 1 页之前） |
| 1 | 插入到文档末尾（默认） |
| 2 | 插入到 `targetPageNum` 指定的页码附近，由 `insertBeforeTarget` 控制前后 |

## 打印适应模式 (fit) 位标志

位标志（bit flags），可按位 OR 组合使用。

**引用位置**：

| 对象 | 成员 | 说明 |
|------|------|------|
| Document | Print | 参数 fit |
| Document | PrintPages | 参数 fit |
| Document | PrintPagesEx | 参数 fit |
| Document | PrintMultipage | 参数 fit |
| Document | PrintBooklet | 参数 fit |

### 枚举值

| **十六进制** | **十进制** | **名称** | **说明** |
| :------ | :------ | :------ | :------ |
| `0x1` | 1 | rawSize | 原始大小（不缩放） |
| `0x10` | 16 | fitItemSize | 适应页面大小 |
| `0x100` | 256 | autoScaleBigPage | 自动缩小超出纸张的页面 |
| `0x1000` | 4096 | specialScale | 使用指定比例（需配合 `specialScale` 参数） |
| `0x10000` | 65536 | autoRotate | 自动旋转以适应纸张方向 |
| `0x100000` | 1048576 | rotate90 | 旋转 90° |
| `0x1000000` | 16777216 | rotate180 | 旋转 180° |
| `0x10000000` | 268435456 | rotate270 | 旋转 270° |

## 视图旋转 (viewRotation)

**引用位置**：

| 对象 | 成员 | 说明 |
|------|------|------|
| View | ViewRotation | 属性 viewRotation |
| View | SetViewRotation | 参数 viewRotation |

### 枚举值

| **值** | **旋转角度** | **说明** |
| :------ | :------ | :------ |
| 0 | 0° | 不旋转（默认） |
| 1 | 90° | 顺时针旋转 90° |
| 2 | 180° | 旋转 180° |
| 3 | 270° | 顺时针旋转 270°（即逆时针 90°） |
