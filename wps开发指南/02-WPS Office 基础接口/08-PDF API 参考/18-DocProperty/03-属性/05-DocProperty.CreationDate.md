# DocProperty.CreationDate

获取文档创建日期。 **String** 类型，只读。

## 语法

express.**CreationDate**

express   一个代表 **DocProperty** 对象的变量。

## 类型

string


## 说明

返回格式固定为 `YYYY-MM-DD HH:MM:SS`，例如 `2026-05-26 15:08:45`。

## 示例

```JavaScript
console.log("创建日期: " + prop.CreationDate);
```
