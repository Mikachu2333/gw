# Clipboard 对象

`Clipboard` 对象用于操作系统剪切板。

## 说明


通过 `app.Clipboard` 访问。

## 示例


```JavaScript
app.Clipboard.Clear();
```

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Clear](/app-integration-dev/wps365/client/wpsoffice/jsapi/pdf/Clipboard/member/Clear) | 清空剪切板。 |
| [GetText](/app-integration-dev/wps365/client/wpsoffice/jsapi/pdf/Clipboard/member/GetText) | 获取剪切板中的文本。 |
| [SetText](/app-integration-dev/wps365/client/wpsoffice/jsapi/pdf/Clipboard/member/SetText) | 设置剪切板文本。 |
| [SetTextFromSelect](/app-integration-dev/wps365/client/wpsoffice/jsapi/pdf/Clipboard/member/SetTextFromSelect) | 将当前选区的文本复制到剪切板。 |
