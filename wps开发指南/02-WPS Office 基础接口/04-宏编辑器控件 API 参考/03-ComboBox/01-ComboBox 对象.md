# ComboBox 对象

组合框由一个文本输入控件和一个下拉菜单组成，用户可以从预先定义的列表中的选择一个选项，同时也可以直接通过文本框输入

## 说明

组合框由一个文本输入控件和一个下拉菜单组成，用户可以从预先定义的列表中的选择一个选项，同时也可以直接通过文本框输入

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [AddItem](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ComboBox/member/AddItem) | 将新项目添加到指定组合框控件显示的值列表中。 |
| [Clear](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ComboBox/member/Clear) | 清除列表框中的所有选项 |
| [DropDown](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ComboBox/member/DropDown) | 您可以使用 Dropdown 方法强制指定组合框中的列表下拉。 |
| [Move](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ComboBox/member/Move) | 将对象移动到参数指定的位置 |
| [RemoveItem](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ComboBox/member/RemoveItem) | 从指定组合框控件显示的值列表中删除项目。 |
