# ListBox 对象

用来显示用户可以选择的项目列表。如果不能一次显示全部项目的话，列表可以滚动。

## 说明

用来显示用户可以选择的项目列表。如果不能一次显示全部项目的话，列表可以滚动。

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [AddItem](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/AddItem) | 将新项目添加到指定组合框控件显示的值列表中。 |
| [Clear](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/Clear) | 清除列表框中的所有选项 |
| [List](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/List) | 设置或获取列表框中的元素 | 
| [Move](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/Move) | 将对象移动到参数指定的位置 |
| [RemoveItem](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/RemoveItem) | 从指定组合框控件显示的值列表中删除项目 |
| [Selected](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/ListBox/member/Selected) | 设置或获取列表框的选中项 |
