# UserForm 对象

UserForm 对象是构成应用程序用户界面的一部分的窗口或对话框。

## 说明

用户窗体对象，是一个容器。代表用户创建的窗体，用户可以向其中添加控件，通过该可以调用添加的控件对象，修改对象的属性，调用对象的方法。

{#objmember}

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Controls](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Controls) | 返回控件的窗体、子窗体、报告或者区块的控件合集 |
| [Hide](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Hide) | 隐藏UserForm对象但不卸载该对象 |
| [Move](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Move) | 将对象移动到参数指定的位置 |
| [Show](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Show) | 显示一个用户窗体对象 |

| :------ | :------- |
| [BackColor](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/BackColor) | 返回或指定当前对象的背景颜色 |
| [BorderColor](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/BorderColor) | 返回当前对象的边框颜色，只读 |
| [Caption](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Caption) | 返回用来识别或描述对象的显示在对象上的描述性文字，只读 |
| [Enabled](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Enabled) | 返回该控件是否能接收焦点或者对用户生成的事件进行响应，只读 |
| [Font](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Font) | 返回对象的字体，只读 |
| [ForeColor](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/ForeColor) | 返回或指定对象的前景颜色 |
| [Height](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Height) | 返回或指定以像素点表示的对象的高 |
| [Left](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Left) | 返回或指定控件到包含它的窗体的左边缘的距离 |
| [Name](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Name) | 返回控件或对象的名称，或与Font对象关联的字体对象的名称，只读 |
| [StartUpPostion](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/StartUpPostion) | 返回或者指定UserForm第一次出现的位置 |
| [Top](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Top) | 返回或指定控件到包含它的窗体的上边缘的距离 |
| [Width](/app-integration-dev/wps365/client/wpsoffice/jsapi/macro-editor-control-api/UserForm/member/Width) | 返回或指定以像素点表示的对象的宽 |
