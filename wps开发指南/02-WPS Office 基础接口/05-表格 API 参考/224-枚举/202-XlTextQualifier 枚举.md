# XlTextQualifier 枚举

指定用于指定文本的分隔符。 

| 名称                             | 值      | 说明       |
| ------------------------------ | ------ | -------- |
| **xlTextQualifierDoubleQuote** | 1      | 双引号 (")。 |
| **xlTextQualifierNone**        | \-4142 | 无分隔符。    |
| **xlTextQualifierSingleQuote** | 2      | 单引号 (')。 |
