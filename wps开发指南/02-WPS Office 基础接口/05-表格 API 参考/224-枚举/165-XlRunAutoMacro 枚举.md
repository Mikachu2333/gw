# XlRunAutoMacro 枚举

指定要运行的自动宏。 

| 名称                   | 值 | 说明                 |
| -------------------- | - | ------------------ |
| **xlAutoActivate**   | 3 | Auto\_Activate 宏   |
| **xlAutoClose**      | 2 | Auto\_Close 宏      |
| **xlAutoDeactivate** | 4 | Auto\_Deactivate 宏 |
| **xlAutoOpen**       | 1 | Auto\_Open 宏       |
