# XlSourceType 枚举

标识源对象。

| 名称                     | 值 | 说明            |
| ---------------------- | - | ------------- |
| **xlSourceAutoFilter** | 3 | “自动筛选”区域      |
| **xlSourceChart**      | 5 | 图表            |
| **xlSourcePivotTable** | 6 | 数据透视表         |
| **xlSourcePrintArea**  | 2 | 选定的用于打印的单元格区域 |
| **xlSourceQuery**      | 7 | 查询表（外部数据区域）   |
| **xlSourceRange**      | 4 | 单元格区域         |
| **xlSourceSheet**      | 1 | 整张工作表         |
| **xlSourceWorkbook**   | 0 | 工作簿           |
