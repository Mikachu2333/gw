# XlPhoneticAlignment 枚举

指定拼音文字的对齐方式。用于 **Phonetic** 或 **Phonetics** 对象。 

| 名称                             | 值 | 说明        |
| ------------------------------ | - | --------- |
| **xlPhoneticAlignCenter**      | 2 | 居中对齐      |
| **xlPhoneticAlignDistributed** | 3 | 分散对齐      |
| **xlPhoneticAlignLeft**        | 1 | 左对齐       |
| **xlPhoneticAlignNoControl**   | 0 | ET 控制对齐方式 |
