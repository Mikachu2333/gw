# XlSpanishModes 枚举

指定西班牙语拼写检查模式。   

| 名称                         | 值 | 说明                  |
| -------------------------- | - | ------------------- |
| **xlSpanishTuteoAndVoseo** | 1 | Tuteo 和 Voseo 动词形式。 |
| **xlSpanishTuteoOnly**     | 0 | 仅 Tuteo 动词形式。       |
| **xlSpanishVoseoOnly**     | 2 | 仅 Voseo 动词形式。       |
