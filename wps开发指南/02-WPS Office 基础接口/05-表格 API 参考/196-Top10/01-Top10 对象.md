# Top10 对象

代表条件格式规则的前十项。通过对某一区域应用颜色，有助于查看相对于其他单元格的单元格的值。

## 说明


所有条件格式设置对象都包含在 **[FormatConditions](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/FormatConditions/obj)** 集合对象中，该对象是 **[Range](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Range/obj)** 集合的子对象。

可以使用 **FormatConditions** 集合的 **[Add](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/FormatConditions/member/Add)** 或 **[AddTop10](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/FormatConditions/member/AddTop10)** 方法创建前 10 个格式规则。


## 示例


```JavaScript
/*本示例通过条件格式规则生成一个动态数据集并对前 10 个值应用颜色。*/
function test() {
    //Building data
    Application.Range("A1").Value2 = "Name"
    Application.Range("B1").Value2 = "Number"
    Application.Range("A2").Value2 = "Agent1"
    Application.Range("A2").AutoFill(Application.Range("A2:A26"), xlFillDefault)
    Application.Range("B2:B26").FormulaArray = "=INT(RAND()*101)"
    Application.Range("B2:B26").Select()

    //Applying Conditional Formatting Top 10
    Application.Selection.FormatConditions.AddTop10()
    Application.Selection.FormatConditions.Item(Application.Selection.FormatConditions.Count).SetFirstPriority()
    let top = Application.Selection.FormatConditions.Item(1)
    top.TopBottom = xlTop10Top
    top.Rank = 10
    top.Percent = false

    //Applying color fill
    let font = Application.Selection.FormatConditions.Item(1).Font
    font.Color = RGB(0, 155, 115)
    font.TintAndShade = 0
    let interior = Application.Selection.FormatConditions.Item(1).Interior
    interior.PatternColorIndex = xlAutomatic
    interior.Color = RGB(5, 185, 115)
    interior.TintAndShade = 0
}
```


```JavaScript
/*本示例设置第一张工作表上区域 E1:E10 中第一个（Top10）条件格式的TopBottom属性，并将该条件格式设置为按百分比值确定排位，然后设置该条件格式的排位值的百分比。*/
function test() {
    let top = Worksheets.Item(1).Range("E1:E10").FormatConditions.Item(1)
    top.TopBottom = xlTop10Bottom
    top.Percent = true
    top.Rank = 20
}
```

## 方法

| **名称** | **说明** |
| :------ | :------- |
| [Delete](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Delete) | 删除指定的条件格式规则对象。 |
| [ModifyAppliesToRange](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/ModifyAppliesToRange) | 设置此格式规则所应用于的单元格区域。 |
| [SetFirstPriority](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/SetFirstPriority) | 将此条件格式规则的优先级值设置为“1”，以便在工作表上的所有其他规则之前计算此规则。 |
| [SetLastPriority](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/SetLastPriority) | 为此条件格式规则设置求值顺序，以便在工作表上的所有其他规则之后计算此规则。 |
## 属性

| **名称** | **说明** |
| :------ | :------- |
| [Application](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Application) | 如果不与对象识别符一起使用，则此属性返回代表 ET 应用程序的 **Application** 对象。如果与对象识别符一起使用，则此属性返回代表指定对象的创建者的 **Application** 对象。只读 |
| [AppliesTo](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/AppliesTo) | 返回一个 **Range** 对象，指定格式规则将应用于的单元格区域。 |
| [Borders](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Borders) | 返回一个 **Borders** 集合，该集合在条件格式规则的计算结果为 **True** 时指定单元格边框的格式。只读。 |
| [Creator](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Creator) | 返回一个 32 位整数，该整数指示在其中创建此对象的应用程序。只读 **Long** 类型。 |
| [Font](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Font) | 返回一个 **Font** 对象，该对象在条件格式规则的计算结果为 **True** 时指定字体格式。只读。 |
| [Interior](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Interior) | 返回一个 **Interior** 对象，该对象在条件格式规则的计算结果为 **True** 时指定单元格的内部属性。只读。 |
| [NumberFormat](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/NumberFormat) | 在条件格式规则的计算结果为 **True** 时返回或设置应用于单元格的数字格式。 **Variant** 型，可读写。 |
| [Parent](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Parent) | 返回指定对象的父对象。只读。 |
| [Percent](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Percent) | 返回或设置一个 **Boolean** 值，指定是否按百分比值确定排位。 |
| [Priority](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Priority) | 返回或设置条件格式规则的优先级值。当工作表中存在多个条件格式规则时，优先级确定求值的顺序。 |
| [Rank](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Rank) | 返回或设置一个 **Long** 值，为条件格式规则指定排位值的数值或百分比。 |
| [StopIfTrue](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/StopIfTrue) | 返回或设置一个 **Boolean** 值，该值确定在当前规则的计算结果为 **True** 时是否应计算单元格上的其他格式规则。 |
| [TopBottom](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/TopBottom) | 返回或设置 **XlTopBottom** 枚举的常量之一，该常量决定是从顶端还是从底端开始计算排位。 |
| [Type](/app-integration-dev/wps365/client/wpsoffice/jsapi/et/Top10/member/Type) | 返回 **XlFormatConditionType** 枚举的常量之一，该常量指定条件格式的类型。只读。 |
