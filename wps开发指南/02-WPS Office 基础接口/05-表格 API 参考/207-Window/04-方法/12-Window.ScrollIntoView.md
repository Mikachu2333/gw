# Window.ScrollIntoView

滚动文档窗口，使指定矩形区域中的内容显示在文档窗口或窗格的左上角或右下角（取决于 _Start_ 参数值）。



## 语法

express.**ScrollIntoView(Left, Top, Width, Height, Start)**

express   一个代表 **Window** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Left | 必选 | number（int4 精度） | 矩形距离文档窗口或窗格左边的水平位置（以磅为单位）。 |
| Top | 必选 | number（int4 精度） | 矩形距离文档窗口或窗格上边的垂直位置（以磅为单位）。 |
| Width | 必选 | number（int4 精度） | 矩形的宽度（以磅为单位）。 |
| Height | 必选 | number（int4 精度） | 矩形的高度（以磅为单位）。 |
| Start | 可选 | any | 如果为 **True** ，则使矩形的左上角位于文档窗口或窗格的左上角。如果为 **False** ，则使矩形的右下角位于文档窗口或窗格的右下角。默认值是 **True** 。 |

## 返回值

void

## 说明


当矩形比文档窗口或窗格大时，_Start_ 参数对调整屏幕显示很有用处。



## 示例


```JavaScript
/*本示例在当前活动窗口中定义一个 100x200 像素的矩形，其位置为距窗口顶部 20 像素，距窗口左边缘 50 像素。然后将文档向左、向上滚动，以使矩形的左上角与窗口的左上角对齐。*/
function test() {
    ActiveWindow.ScrollIntoView(50, 20, 100, 200)
}
```


```JavaScript
/*本示例在第一个窗口中定义一个 300x500 像素的矩形，其位置为距窗口顶部 200 像素，距窗口左边缘 1000 像素。然后将文档向右、向下滚动，以使矩形的右下角与窗口的右下角对齐。*/
function test() {
    Windows.Item(1).ScrollIntoView(1000, 200, 300, 500, false)
}
```
