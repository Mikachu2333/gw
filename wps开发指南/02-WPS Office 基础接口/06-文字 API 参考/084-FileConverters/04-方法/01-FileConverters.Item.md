# FileConverters.Item

返回集合中的单个 **FileConverter** 对象。



## 语法

express.**Item(Index)**

express   一个代表 **FileConverters** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Index | 必选 | any | 要返回的单个对象。可以是代表序号位置的 Long 类型值，或代表单个对象名称的 String 类型值。 |

## 返回值

FileConverter
