# WdDefaultListBehavior 枚举

指定列表的默认列表行为。

| 名称                       | 值 | 说明                        |
| ------------------------ | - | ------------------------- |
| **wdWord10ListBehavior** | 2 | 使用与 WPS 2002 兼容的格式。       |
| **wdWord8ListBehavior**  | 0 | 使用与 WPS 97 兼容的格式。         |
| **wdWord9ListBehavior**  | 1 | 使用在 WPS 2000 中引入的面向网站的格式。 |
