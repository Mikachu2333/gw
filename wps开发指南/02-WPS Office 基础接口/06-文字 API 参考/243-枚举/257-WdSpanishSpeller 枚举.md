# WdSpanishSpeller 枚举

指定西班牙语拼写器模式。  

| 名称                         | 值 | 说明                             |
| -------------------------- | - | ------------------------------ |
| **wdSpanishTuteoAndVoseo** | 1 | 西班牙语拼写检查器可识别 tuteo 和 voseo 动词。 |
| **wdSpanishTuteoOnly**     | 0 | 西班牙语拼写检查器仅识别 tuteo 动词。         |
| **wdSpanishVoseoOnly**     | 2 | 西班牙语拼写检查器仅识别 voseo 动词。         |
