# WdHighAnsiText 枚举

指定 WPS 如何解释高端 ANSI 字符。

| 名称                              | 值 | 说明                                               |
| ------------------------------- | - | ------------------------------------------------ |
| **wdAutoDetectHighAnsiFarEast** | 2 | 只有在 WPS 自动检测到东亚语言文字时， WPS 才将高端 ANSI 字符译码为东亚语言字符。 |
| **wdHighAnsiIsFarEast**         | 0 | WPS 不将任何高端 ANSI 字符译码为东亚字符。                       |
| **wdHighAnsiIsHighAnsi**        | 1 | WPS 将所有高端 ANSI 字符译码为东亚字符。                        |
