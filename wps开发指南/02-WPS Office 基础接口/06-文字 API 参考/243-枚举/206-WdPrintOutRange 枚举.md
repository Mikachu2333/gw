# WdPrintOutRange 枚举

指定要打印的范围。

| 名称                      | 值 | 说明       |
| ----------------------- | - | -------- |
| **wdPrintAllDocument**  | 0 | 整个文档。    |
| **wdPrintCurrentPage**  | 2 | 当前页面。    |
| **wdPrintFromTo**       | 3 | 指定范围。    |
| **wdPrintRangeOfPages** | 4 | 指定的页面范围。 |
| **wdPrintSelection**    | 1 | 当前所选内容。  |
