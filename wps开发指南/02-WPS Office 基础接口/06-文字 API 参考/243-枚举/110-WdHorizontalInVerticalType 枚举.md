# WdHorizontalInVerticalType 枚举

指定竖排文字中设置的横向文字格式。

| 名称                                   | 值 | 说明             |
| ------------------------------------ | - | -------------- |
| **wdHorizontalInVerticalFitInLine**  | 1 | 根据竖排文字行调整横向文字。 |
| **wdHorizontalInVerticalNone**       | 0 | 不对横向文字应用格式。    |
| **wdHorizontalInVerticalResizeLine** | 2 | 根据横向文字调整竖排文字行。 |
