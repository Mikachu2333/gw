# WdContentControlAppearance 枚举

指定内容控件的可视化效果，该控件传递给 ContentControl.Appearance 属性并由其返回。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **wdContentControlBoundingBox** | 0 | 表示显示为带阴影矩形或边框的内容控件，（具有可选标题）。 |
| **wdContentControlTags** | 1 | 表示显示为开始标记和结束标记的内容控件。 |
| **wdContentControlHidden** | 2 | 表示未显示的内容控件。 |
