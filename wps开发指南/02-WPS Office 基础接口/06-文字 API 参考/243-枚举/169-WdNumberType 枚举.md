# WdNumberType 枚举

指定编号的类型。

| 名称                     | 值 | 说明                                       |
| ---------------------- | - | ---------------------------------------- |
| **wdNumberAllNumbers** | 3 | 其他所有情况下的默认值。                             |
| **wdNumberListNum**    | 2 | LISTNUM 域的默认值。                           |
| **wdNumberParagraph**  | 1 | 可通过在**“项目符号和编号”**对话框中选择模板的方式添加到段落中的预设编号。 |
