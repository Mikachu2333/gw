# WdSortSeparator 枚举

指定域分隔符的类型。

| 名称                                        | 值 | 说明       |
| ----------------------------------------- | - | -------- |
| **wdSortSeparateByCommas**                | 1 | 逗号。      |
| **wdSortSeparateByDefaultTableSeparator** | 2 | 默认表格分隔符。 |
| **wdSortSeparateByTabs**                  | 0 | 制表符。     |
