# WdCharacterCase 枚举

为指定范围内的文字指定大小写。

| 名称                  | 值   | 说明                 |
| ------------------- | --- | ------------------ |
| **wdFullWidth**     | 7   | 全角，用于日语字符。         |
| **wdHalfWidth**     | 6   | 半角，用于日语字符。         |
| **wdHiragana**      | 9   | 平假名字符，用于日语文字。      |
| **wdKatakana**      | 8   | 片假名字符，用于日语文字。      |
| **wdLowerCase**     | 0   | 小写。                |
| **wdNextCase**      | \-1 | 在大写、小写和句首字母大写之间切换。 |
| **wdTitleSentence** | 4   | 句首字母大写。            |
| **wdTitleWord**     | 2   | 标题字大写。             |
| **wdToggleCase**    | 5   | 在大写和小写之间切换。        |
| **wdUpperCase**     | 1   | 大写。                |
