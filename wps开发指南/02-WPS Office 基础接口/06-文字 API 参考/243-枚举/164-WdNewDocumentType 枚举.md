# WdNewDocumentType 枚举

指定要创建的新文档的类型。

| 名称                     | 值 | 说明      |
| ---------------------- | - | ------- |
| **wdNewBlankDocument** | 0 | 空白文档。   |
| **wdNewEmailMessage**  | 2 | 电子邮件。   |
| **wdNewFrameset**      | 3 | 框架集。    |
| **wdNewWebPage**       | 1 | 网页。     |
| **wdNewXMLDocument**   | 4 | XML 文档。 |
