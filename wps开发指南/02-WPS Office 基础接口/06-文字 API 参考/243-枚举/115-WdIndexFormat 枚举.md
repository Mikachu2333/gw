# WdIndexFormat 枚举

指定文档中索引的格式。

| 名称                  | 值 | 说明    |
| ------------------- | - | ----- |
| **wdIndexBulleted** | 4 | 项目符号。 |
| **wdIndexClassic**  | 1 | 古典型。  |
| **wdIndexFancy**    | 2 | 流行。   |
| **wdIndexFormal**   | 5 | 正式。   |
| **wdIndexModern**   | 3 | 现代。   |
| **wdIndexSimple**   | 6 | 简明型。  |
| **wdIndexTemplate** | 0 | 来自模板。 |
