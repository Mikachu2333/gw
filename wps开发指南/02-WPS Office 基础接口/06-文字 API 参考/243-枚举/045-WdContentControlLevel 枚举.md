# WdContentControlLevel 枚举

指定 ContentControl.Level 属性返回的内容控件的可能级别。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **wdContentControlLevelCell** | 3 | 表示表单元格周围的内容控件。 |
| **wdContentControlLevelInline** | 0 | 表示一个内容控件，该控件将内容括在单个段落内。 |
| **wdContentControlLevelParagraph** | 1 | 表示包围一个或多个完整段落的内容控件。 |
| **wdContentControlLevelRow** | 2 | 表示包围表行的内容控件。 |
