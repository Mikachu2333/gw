# WdOrganizerObject 枚举

指定删除、复制或重命名操作所使用的对象的类型。

| 名称                                | 值 | 说明      |
| --------------------------------- | - | ------- |
| **wdOrganizerObjectAutoText**     | 1 | 自动图文集项。 |
| **wdOrganizerObjectCommandBars**  | 2 | 命令栏项。   |
| **wdOrganizerObjectProjectItems** | 3 | 方案项。    |
| **wdOrganizerObjectStyles**       | 0 | 样式项。    |
