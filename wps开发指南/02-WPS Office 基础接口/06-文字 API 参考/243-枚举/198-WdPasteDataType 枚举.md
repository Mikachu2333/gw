# WdPasteDataType 枚举

指定将剪贴板内容插入到文档时采用的格式。

| 名称                                 | 值  | 说明        |
| ---------------------------------- | -- | --------- |
| **wdPasteBitmap**                  | 4  | 位图。       |
| **wdPasteDeviceIndependentBitmap** | 5  | 与设备无关的位图。 |
| **wdPasteEnhancedMetafile**        | 9  | 增强型图元文件。  |
| **wdPasteHTML**                    | 10 | HTML。     |
| **wdPasteHyperlink**               | 7  | 超链接。      |
| **wdPasteMetafilePicture**         | 3  | 图元文件图片。   |
| **wdPasteOLEObject**               | 0  | OLE 对象。   |
| **wdPasteRTF**                     | 1  | RTF 格式。   |
| **wdPasteShape**                   | 8  | 形状。       |
| **wdPasteText**                    | 2  | 文本。       |
