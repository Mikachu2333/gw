# WdPageColor 枚举

指定阅读模式下的背景页面颜色，由 View.PageColor 返回或传入。

| 名称              | 值 | 说明 |
| ----------------- | ---- | ---- |
| **wdPageColorInverse** | 2 | 反转页面颜色。以类似于高对比度黑色的方式呈现文档内容，尽管不一定完全如此。某些图形在黑色背景上以全彩色呈现。 |
| **wdPageColorNone** | 0 | 无页面颜色，默认值。页面背景以白色呈现。将忽略任何分配的页面背景色。 |
| **wdPageColorSepia** | 1 | 棕褐色页面颜色，RGB (112, 66, 20) ，透明度为 80%。不对文档的内容进行更改。 |
