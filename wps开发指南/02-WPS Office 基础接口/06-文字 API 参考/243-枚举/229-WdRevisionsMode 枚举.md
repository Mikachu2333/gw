# WdRevisionsMode 枚举

指定 WPS 是在边距中显示气球还是在文档正文内部显示气球。

| 名称                     | 值 | 说明                                             |
| ---------------------- | - | ---------------------------------------------- |
| **wdBalloonRevisions** | 0 | 在左边距或右边距的气球中显示修订。                              |
| **wdInLineRevisions**  | 1 | 在正文中显示修订，使用删除线表示删除，使用下划线表示插入。这是 WPS 早期版本的默认设置。 |
| **wdMixedRevisions**   | 2 | 不支持。                                           |
