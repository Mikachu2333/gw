# WdExportFormat 枚举

指定用于导出文档的格式。

| 名称                    | 值  | 说明                                       |
| --------------------- | -- | ---------------------------------------- |
| **wdExportFormatPDF** | 17 | 将文档导出为 PDF 格式。                           |
| **wdExportFormatXPS** | 18 | 将文档导出为 XML Paper Specification (XPS) 格式。 |
