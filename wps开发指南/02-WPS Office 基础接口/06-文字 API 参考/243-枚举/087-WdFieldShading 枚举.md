# WdFieldShading 枚举

指定何时应用窗体域的屏幕底纹。

| 名称                             | 值 | 说明           |
| ------------------------------ | - | ------------ |
| **wdFieldShadingAlways**       | 1 | 始终应用。        |
| **wdFieldShadingNever**        | 0 | 从不应用。        |
| **wdFieldShadingWhenSelected** | 2 | 只在选中窗体域时才应用。 |
