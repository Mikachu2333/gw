# WdFarEastLineBreakLanguageID 枚举

指定在所指定文档或模板中对文本进行换行时使用的东亚语言。

| 名称                                | 值    | 说明    |
| --------------------------------- | ---- | ----- |
| **wdLineBreakJapanese**           | 1041 | 日语。   |
| **wdLineBreakKorean**             | 1042 | 朝鲜语。  |
| **wdLineBreakSimplifiedChinese**  | 2052 | 简体中文。 |
| **wdLineBreakTraditionalChinese** | 1028 | 繁体中文。 |
