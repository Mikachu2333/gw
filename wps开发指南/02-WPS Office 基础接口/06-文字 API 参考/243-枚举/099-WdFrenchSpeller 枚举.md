# WdFrenchSpeller 枚举

指示在使用法语拼写检查词典时所使用的法语版本。

| 名称                     | 值 | 说明                         |
| ---------------------- | - | -------------------------- |
| **wdFrenchBoth**       | 0 | 在检查法语拼写时同时使用后期修订和前期修订法语词典。 |
| **wdFrenchPostReform** | 2 | 在检查法语拼写时只使用后期修订法语词典。       |
| **wdFrenchPreReform**  | 1 | 在检查法语拼写时只使用前期修订法语词典。       |
