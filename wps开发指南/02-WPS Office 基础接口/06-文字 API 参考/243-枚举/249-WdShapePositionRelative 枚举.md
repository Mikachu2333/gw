# WdShapePositionRelative 枚举

指定 **Shape** 或   **ShapeRange** 对象的 **LeftRelative** 或 **TopRelative** 属性是否有效。

| 名称                              | 值        | 说明                                                                                  |
| ------------------------------- | -------- | ----------------------------------------------------------------------------------- |
| **wdShapePositionRelativeNone** | \-999999 | 指定 **LeftRelative** 或 **TopRelative** 属性当前无效，因此分别根据 **Left** 或 **Top** 属性中指定的值放置形状。 |
