# WdPageFit 枚举

指定页面的视图设置。

| 名称                    | 值 | 说明             |
| --------------------- | - | -------------- |
| **wdPageFitBestFit**  | 2 | 使页面最佳匹配活动窗口。   |
| **wdPageFitFullPage** | 1 | 查看整个页面。        |
| **wdPageFitNone**     | 0 | 不要为页面调整视图设置。   |
| **wdPageFitTextFit**  | 3 | 使页面文本最佳匹配活动窗口。 |
