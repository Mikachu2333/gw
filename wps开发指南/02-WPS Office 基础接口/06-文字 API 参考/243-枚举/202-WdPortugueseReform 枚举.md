# WdPortugueseReform 枚举

指定巴西或欧洲葡萄牙语拼写器的模式。可读/写。

| 名称                         | 值 | 说明               |
| -------------------------- | - | ---------------- |
| **wdPortugueseBoth**       | 3 | 使用前期修订和后期修订拼写规则。 |
| **wdPortuguesePostReform** | 2 | 使用后期修订拼写规则。      |
| **wdPortuguesePreReform**  | 1 | 使用前期修订拼写规则。      |
