# WdArabicNumeral 枚举

为阿拉伯语文档指定数字样式。

| 名称                   | 值 | 说明              |
| -------------------- | - | --------------- |
| **wdNumeralArabic**  | 0 | 数字采用阿拉伯语形状。     |
| **wdNumeralContext** | 2 | 数字形状取决于数字周围的文字。 |
| **wdNumeralHindi**   | 1 | 数字采用印地语形状。      |
| **wdNumeralSystem**  | 3 | 数字形状由系统设置决定。    |
