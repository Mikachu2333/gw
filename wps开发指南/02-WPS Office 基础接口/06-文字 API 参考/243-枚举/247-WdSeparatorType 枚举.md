# WdSeparatorType 枚举

指定要在各项之间放置的分隔符的类型。

| 名称                    | 值 | 说明       |
| --------------------- | - | -------- |
| **wdSeparatorColon**  | 2 | 冒号。      |
| **wdSeparatorEmDash** | 3 | 着重突出的划线。 |
| **wdSeparatorEnDash** | 4 | 标准划线。    |
| **wdSeparatorHyphen** | 0 | 连字符。     |
| **wdSeparatorPeriod** | 1 | 句点。      |
