# WdMailSystem 枚举

指定邮件系统的类型。

| 名称                     | 值 | 说明                                        |
| ---------------------- | - | ----------------------------------------- |
| **wdMAPI**             | 1 | 标准邮件应用程序编程接口 (MAPI) 邮件系统。                 |
| **wdMAPIandPowerTalk** | 3 | 标准邮件应用程序编程接口 (MAPI) 邮件系统和 PowerTalk 邮件系统。 |
| **wdNoMailSystem**     | 0 | 没有邮件系统。                                   |
| **wdPowerTalk**        | 2 | PowerTalk 邮件系统。                           |
