# WdEmailHTMLFidelity 枚举

指定是保留还是删除显示内容时不需要的 HTML 标记。

| 名称                            | 值 | 说明                      |
| ----------------------------- | - | ----------------------- |
| **wdEmailHTMLFidelityHigh**   | 3 | 按原样保留 HTML 标记。          |
| **wdEmailHTMLFidelityLow**    | 1 | 删除不影响消息显示方式的所有 HTML 标记。 |
| **wdEmailHTMLFidelityMedium** | 2 | 不支持。                    |
