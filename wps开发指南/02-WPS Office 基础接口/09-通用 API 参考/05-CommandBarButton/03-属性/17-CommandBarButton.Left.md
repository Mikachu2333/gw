# CommandBarButton.Left

设置或获取指定的 **CommandBarButton** 控件相对于屏幕左边缘的水平位置（以像素为单位）。返回距离停靠区域左侧的距离。只读。




## 语法

express.**Left**

express   一个代表 **CommandBarButton** 对象的变量。

## 类型

number（int 精度）

## 说明


| 注释                                                                   |
| -------------------------------------------------------------------- |
