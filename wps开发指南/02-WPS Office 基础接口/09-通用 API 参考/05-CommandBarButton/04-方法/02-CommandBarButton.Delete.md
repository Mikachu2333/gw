# CommandBarButton.Delete

将 **CommandBarButton** 对象从其集合中删除。



## 语法

express.**Delete(Temporary)**

express   一个代表 **CommandBarButton** 对象的变量。

## 参数

| **名称** | **必选/可选** | **数据类型** | **说明** |
| :------ | :------------ | :---------- | :------- |
| Temporary | 可选 | any | 如果为 true，则从当前会话中删除此控件。应用程序在下次会话中将再次显示该控件。 |

## 返回值

void
