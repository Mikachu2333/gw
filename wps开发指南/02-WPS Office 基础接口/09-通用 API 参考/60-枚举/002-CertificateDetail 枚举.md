# CertificateDetail 枚举

提供有关数字证书的信息。

| 名称                        | 值 | 说明            |
| ------------------------- | - | ------------- |
| **certdetAvailable**      | 0 | 指定可用于签署的数字证书。 |
| **certdetExpirationDate** | 3 | 证书的到期日期。      |
| **certdetIssuer**         | 2 | 证书的颁发机构。      |
| **certdetSubject**        | 1 | 对应于公钥的私钥的持有者。 |
| **certdetThumbprint**     | 4 | 证书的全部内容的哈希。   |
