# XlColorIndex 枚举

指定所选功能（如边框、字体或填充）的颜色。可使用下列特殊常量，也可指定 1–56 的整数值表示当前工作簿调色板中对应位置的颜色。

## 常量

| 名称                        | 值      | 说明    |
| ------------------------- | ------ | ----- |
| **xlColorIndexAutomatic** | \-4105 | 自动配色。 |
| **xlColorIndexNone**      | \-4142 | 无色。   |

## 调色板索引

每个工作簿拥有独立的 56 色调色板，可通过 **Workbook.Colors** 属性读取或修改。ColorIndex 的 1–56 对应的是调色板中该位置的颜色，而非固定颜色值——如果用户或代码修改了调色板，同一索引号对应的实际颜色会随之改变。
