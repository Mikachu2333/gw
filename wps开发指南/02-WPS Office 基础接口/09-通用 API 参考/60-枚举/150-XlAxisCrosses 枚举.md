# XlAxisCrosses 枚举

指定所指定的坐标轴与其他坐标轴相交的点。

| 名称                         | 值      | 说明                       |
| -------------------------- | ------ | ------------------------ |
| **xlAxisCrossesAutomatic** | \-4105 | 由 ET 设置坐标轴交点。            |
| **xlAxisCrossesCustom**    | \-4114 | **CrossesAt** 属性指定坐标轴交点。 |
| **xlAxisCrossesMaximum**   | 2      | 坐标轴在最大值处相交。              |
| **xlAxisCrossesMinimum**   | 4      | 坐标轴在最小值处相交。              |
