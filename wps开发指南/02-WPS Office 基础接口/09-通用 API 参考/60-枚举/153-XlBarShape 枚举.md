# XlBarShape 枚举

指定用于三维条形图或柱形图的形状。

| 名称                   | 值 | 说明             |
| -------------------- | - | -------------- |
| **xlBox**            | 0 | 框。             |
| **xlConeToMax**      | 5 | 锥形，在特定值上截断。    |
| **xlConeToPoint**    | 4 | 锥形，在特定值上变成一点。  |
| **xlCylinder**       | 3 | 圆柱形。           |
| **xlPyramidToMax**   | 2 | 金字塔，在特定值上截断。   |
| **xlPyramidToPoint** | 1 | 金字塔，在特定值上变成一点。 |
