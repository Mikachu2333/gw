# MsoSyncVersionType 枚举

指定在当前打开的本地版本旁打开哪个版本的共享文档。

| 注释                                     |
| -------------------------------------- |
| 自 WPS Office 2015 开始，此对象或成员已弃用，不应再行使用。 |

| 名称                           | 值 | 说明                         |
| ---------------------------- | - | -------------------------- |
| **msoSyncVersionLastViewed** | 0 | 打开当用户用服务器副本覆盖本地副本时创建的文档副本。 |
| **msoSyncVersionServer**     | 1 | 打开服务器版本。                   |
