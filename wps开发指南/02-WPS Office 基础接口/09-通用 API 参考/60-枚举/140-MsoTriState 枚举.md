# MsoTriState 枚举

指定 3 状态 **Boolean** 值。

| 名称                    | 值   | 说明     |
| --------------------- | --- | ------ |
| **msoCTrue**          | 1   | 不支持。   |
| **msoFalse**          | 0   | False。 |
| **msoTriStateMixed**  | \-2 | 不支持。   |
| **msoTriStateToggle** | \-3 | 不支持。   |
| **msoTrue**           | \-1 | True。  |
