# MsoHorizontalAnchor 枚举

指定文本框架中文本的水平对齐方式。与 **TextFrame** 对象的 **HorizontalAnchor** 属性一起使用。

| 名称                           | 值   | 说明              |
| ---------------------------- | --- | --------------- |
| **msoAnchorCenter**          | 2   | 文本水平居中。         |
| **msoAnchorNone**            | 1   | 不对齐。            |
| **msoHorizontalAnchorMixed** | \-2 | 只返回值，表示其他状态的组合。 |
