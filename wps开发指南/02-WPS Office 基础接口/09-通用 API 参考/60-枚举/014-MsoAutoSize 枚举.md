# MsoAutoSize 枚举

确定允许的自动调整大小的类型。

| 名称                            | 值   | 说明             |
| ----------------------------- | --- | -------------- |
| **msoAutoSizeMixed**          | \-2 | 使用自动调整大小方案的组合。 |
| **msoAutoSizeNone**           | 0   | 不自动调整大小。       |
| **msoAutoSizeShapeToFitText** | 1   | 根据文本调整形状。      |
| **msoAutoSizeTextToFitShape** | 2   | 根据形状调整文本。      |
