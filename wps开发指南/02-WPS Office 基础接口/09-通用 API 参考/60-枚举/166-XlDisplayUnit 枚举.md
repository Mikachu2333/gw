# XlDisplayUnit 枚举

指定坐标轴的显示单位标签。 

| 名称                     | 值    | 说明  |
| ---------------------- | ---- | --- |
| **xlHundredMillions**  | \-8  | 亿。  |
| **xlHundreds**         | \-2  | 百。  |
| **xlHundredThousands** | \-5  | 十万。 |
| **xlMillionMillions**  | \-10 | 万亿。 |
| **xlMillions**         | \-6  | 百万。 |
| **xlTenMillions**      | \-7  | 千万。 |
| **xlTenThousands**     | \-4  | 万   |
| **xlThousandMillions** | \-9  | 亿。  |
| **xlThousands**        | \-3  | 千。  |
