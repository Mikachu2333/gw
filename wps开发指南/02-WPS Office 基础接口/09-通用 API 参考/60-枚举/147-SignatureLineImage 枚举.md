# SignatureLineImage 枚举

指示签名行图像。

| 名称                           | 值 | 说明                   |
| ---------------------------- | - | -------------------- |
| **siglnimgSignedInvalid**    | 3 | SignedInvalid 图像。    |
| **siglnimgSignedValid**      | 2 | SignedValid 图像。      |
| **siglnimgSoftwareRequired** | 0 | SoftwareRequired 图像。 |
| **siglnimgUnsigned**         | 1 | Unsigned 图像。         |
