| ------------------------------------------------- | ---- | ---- |
| **MsoFarEastLineBreakLanguageJapanese**           | 1041 | 日语   |
| **MsoFarEastLineBreakLanguageKorean**             | 1042 | 朝鲜语  |
| **MsoFarEastLineBreakLanguageSimplifiedChinese**  | 2052 | 简体中文 |
| **MsoFarEastLineBreakLanguageTraditionalChinese** | 1028 | 繁体中文 |
