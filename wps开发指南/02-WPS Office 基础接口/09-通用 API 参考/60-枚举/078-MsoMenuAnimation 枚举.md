# MsoMenuAnimation 枚举

指定 WPS Office命令栏的动画样式。

| 名称                         | 值 | 说明        |
| -------------------------- | - | --------- |
| **msoMenuAnimationNone**   | 0 | 无动画。      |
| **msoMenuAnimationRandom** | 1 | 随机动画。     |
| **msoMenuAnimationSlide**  | 3 | 菜单滑入视图。   |
| **msoMenuAnimationUnfold** | 2 | 菜单展开进入视图。 |
