# CommandBars.Application

获取一个 **Application** 对象，代表 **CommandBars** 对象的容器应用程序（可以使用 **Automation** 对象的此属性返回该对象的容器应用程序）。只读。




## 语法

express.**Application**

express   一个代表 **CommandBars** 对象的变量。

## 类型

Object
