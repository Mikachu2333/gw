# CommandBarComboBox.BuiltIn

如果指定的命令栏控件是容器应用程序的内置控件，则获取 **True** 。如果是自定义控件或是已设置了 **OnAction** 属性的内置控件，则返回 **False** 。只读。




## 语法

express.**BuiltIn**

express   一个代表 **CommandBarComboBox** 对象的变量。

## 类型

boolean
