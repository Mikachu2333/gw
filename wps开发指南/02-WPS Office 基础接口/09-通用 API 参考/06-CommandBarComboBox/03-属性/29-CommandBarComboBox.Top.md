# CommandBarComboBox.Top

获取指定的 **CommandBarComboBox** 控件顶边到屏幕顶边的距离（以像素为单位）。只读。




## 语法

express.**Top**

express   一个代表 **CommandBarComboBox** 对象的变量。

## 类型

number（int 精度）

## 说明


| 注释                                                                   |
| -------------------------------------------------------------------- |
| 在某些 WPS Office应用程序中，CommandBar 已被新的功能区用户界面取代。有关详细信息，请在帮助中搜索关键字“功能区”。 |
