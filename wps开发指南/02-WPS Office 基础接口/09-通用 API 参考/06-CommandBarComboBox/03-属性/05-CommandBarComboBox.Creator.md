# CommandBarComboBox.Creator

获取一个 32 位整数，指示创建 **CommandBarComboBox** 对象时所使用的应用程序。只读。




## 语法

express.**Creator**

express   一个代表 **CommandBarComboBox** 对象的变量。

## 类型

number（int4 精度）

| 注释                                                                   |
