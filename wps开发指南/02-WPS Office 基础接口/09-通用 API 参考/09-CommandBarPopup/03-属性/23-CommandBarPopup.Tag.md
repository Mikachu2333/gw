# CommandBarPopup.Tag

获取或设置有关 **CommandBarPopup** 控件的信息，例如，可作为过程参数的数据或用于识别该控件的信息。可读写。




## 语法

express.**Tag**

express   一个代表 **CommandBarPopup** 对象的变量。

## 类型

string

## 说明


| 注释                                                                   |
| -------------------------------------------------------------------- |
| 在某些 WPS Office应用程序中，CommandBar 已被新的功能区用户界面取代。有关详细信息，请在帮助中搜索关键字“功能区”。 |
